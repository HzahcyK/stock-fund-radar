# Output Template

Use this template for full daily reports. Shorten it when the user asks a narrow question.

## Daily Brief

Start with:

- Data time: `YYYY-MM-DD HH:mm`, timezone, session status.
- Stance: offensive, balanced, defensive, or wait-and-see.
- Top lines: 1-3 themes ranked by confidence.
- Key warning: the single biggest invalidation risk.
- Evidence depth: state whether the answer uses quick tape analysis or deep evidence-chain analysis.
- Event check: one line summarizing the most important geopolitical/policy/summit/news catalyst and whether the tape confirms it.
- Technical check: one line summarizing major-index K-line state and the K-line state of the leading hot sector.

## Suggested Structure

Use this structure for complete daily market/opportunity reports:

1. 今日结论: stance, mainline, risk level, action bias.
2. 事件风险图: geopolitics, latest news, China policy, major summits/meetings, overseas catalysts; list bullish/bearish sector transmission.
3. 外围与全球宏观: US/EU/Asia, rates, dollar/CNH, commodities, VIX.
4. 中国政策与流动性: official policy, PBOC/liquidity, fiscal/property/technology/consumption signals.
5. 大盘技术面: Shanghai Composite, CSI 300, ChiNext, STAR 50; K-line, MA5/10/20/60, volume, support/resistance, breadth.
6. A股盘面与主力资金: turnover, breadth, limit-up/down, sector/concept flows, ETF clues.
7. 热门板块K线确认: daily/weekly K-line, volume, MACD/KDJ/RSI if useful, relative strength, extension/crowding.
8. 财报/业绩/估值证据链: representative companies and fund top holdings when relevant.
9. 主线方向判断: dominant line, likely next line, quiet-start candidates.
10. 基金候选池与操作计划: fund-first entries, triggers, invalidation, position role.
11. 风险、反证与明日观察: what would change the view.

## Deep View Block

For important decisions, include:

- 结论: one decisive view.
- 证据链: event/geopolitics, policy/macro, financial report, capital flow, technicals, valuation.
- 非显而易见的点: one insight beyond涨跌幅.
- 我可能错在哪里: strongest counterargument.
- 操作: position size, trigger, invalidation, next observation.

## Tone

- Be direct and practical.
- Use "关注", "候选", "条件触发", "暂缓" instead of absolute trading commands.
- Mention that fund holdings and NAV data may lag when relevant.
- Keep source links close to the data they support.
