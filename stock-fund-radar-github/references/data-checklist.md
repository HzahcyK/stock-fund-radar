# Data Checklist

Use this checklist for today's market, policy, overseas, or capital-flow questions. Browse because these inputs are time-sensitive.

## Source Hierarchy

- Policy and regulation: State Council, PBOC, CSRC, NDRC, MOF, NBS, SSE, SZSE, BSE, HKEX, official ministry releases.
- Macro and rates: PBOC, NBS, SAFE, ChinaBond, Fed, Treasury, BLS, BEA, ECB, BOJ, IMF, World Bank.
- Market tape: exchange data first where possible; otherwise reputable market-data terminals/sites for live indices, turnover, breadth, sector ranking, ETF activity, and main-fund flow snapshots.
- Funds: fund company pages, exchange fund pages, fund prospectus/regular reports, official sales-platform pages, and reputable fund databases.
- Financial reports: official exchange filings, company annual/quarterly reports, earnings previews, investor relations releases, and fund top-holding disclosures.
- News: use recent, attributable reports. Confirm policy-sensitive claims with official releases whenever possible.

## Required Daily Snapshot

Record the as-of time and timezone for each group:

- Overseas: S&P 500, Nasdaq, Dow, Russell 2000, US 10Y yield, DXY, USD/CNH, gold, copper, crude, VIX, major Asian markets, and key futures if A-shares are not yet open.
- China: Shanghai Composite, CSI 300, ChiNext, STAR 50, A50/China futures if useful, total A-share turnover, advance/decline, limit-up/down, north/southbound data under the current disclosure regime, margin data when available.
- Capital flows: sector/concept main funds, large-order flows, ETF shares/turnover, active fund clues from disclosed holdings only, and high-volume block/industry patterns.
- Technical data for重点板块: daily/weekly K-lines, MA5/10/20/60, volume and turnover trend, MACD/KDJ/RSI when available, recent highs/lows, gaps, support/resistance, and relative strength versus broad indices.
- ETF technical data: ETF daily/intraday K-line, turnover, premium/discount if available, volume change, and whether ETF走势 confirms the underlying sector/index.
- Policy/macro: newest China policy releases, central-bank liquidity operations, fiscal/property/consumption/technology support, macro calendar, and major geopolitical events.
- Financial and valuation data: latest quarterly/annual results of representative companies and fund top holdings; revenue/profit trend, gross margin, cash flow, inventory, orders/backlog, capex, product prices, valuation/crowding, and earnings-revision clues.
- Calendar: earnings, dividends, index rebalances, central-bank meetings, industry conferences, product launches, and commodity inventory/price data.

## Freshness Rules

- Intraday calls need intraday data when available. Post-close calls should use close data.
- Batch live-market requests by asset group, sector group, and ETF/fund group to reduce repeated confirmations and keep the analysis moving.
- Reuse same-session data when it is still fresh enough for the question. Refresh only when the user asks, the market has materially moved, or the prior timestamp is stale for the requested decision.
- If data points disagree across sites, say which one is used and why.
- If a data category is unavailable, mark it "未取到" instead of guessing.
- For funds, use latest disclosed holdings and latest available performance data; do not imply holdings are real-time.
- For technical indicators, state the period used. Intraday K-line is for tactical timing; daily/weekly K-line is for direction and risk control.
- For financial reports, state the reporting period and whether the data is from official filings, consensus estimates, or inferred proxies.
